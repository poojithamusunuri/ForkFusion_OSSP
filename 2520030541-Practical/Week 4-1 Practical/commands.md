# Week 4-1 Practical – Commands

## Navigate to the Practical Directory

```bash
cd ~/Documents/ForkFusion_OSSP/2520030541-Practical/"Week 4-1 Practical"
```

## Create the Program File

```bash
touch week41.c
```

## Open the C Program

```bash
open -a TextEdit week41.c
```

## Compile the Program

```bash
clang week41.c -o week41
```

## Execute the Program

```bash
./week41
```

## List the Files

```bash
ls
```

## Remove the Compiled Executable Before Submission

```bash
rm week41
```

```bash
cd ~/Documents/ForkFusion_OSSP
```
