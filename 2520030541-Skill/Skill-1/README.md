# Skill 1 - Interactive Shell Loop

## Objective

To create a basic interactive shell program that displays a prompt, accepts user input, handles the exit condition, and processes user commands.

## Concepts Used

- Infinite loop using `while(1)`
- Displaying a shell prompt
- Reading user input using `fgets()`
- Character array as an input buffer
- Removing the newline character
- Comparing strings using `strcmp()`
- Handling the `exit` command
- Processing multi-character user input
